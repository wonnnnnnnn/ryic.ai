PowerShell 명령을 실행하는
로컬 PC 제어 에이전트.

자연어로 요청하면 AI가 스스로 필요한 PowerShell 스크립트를 생성하고, 직접 로컬 터미널에 명령어를 입력 및 실행하여 시스템 제어·파일 관리·업무 자동화를 완수합니다.

Tier 02

자율 명령어 실행 및 결과 피드백 루프

권한 모드: PowerShell User/Admin
•
자동 피드백: StdOut Error Loop

Shell Agent Loop (자율 실행 제어)

사용자의 명령을 분석해 PowerShell 매개변수와 커맨드를 스스로 도출합니다. 명령 실행 결과를 실시간 파싱(StdOut/StdErr)하여, 에러 발생 시 자동으로 명령을 수정하고 재시도합니다.

// AI 자율 실행 시나리오 예시
"현재 디렉토리에서 100MB 이상 되는 용량 큰 파일 찾아서 텍스트 파일로 저장해줘"
Get-ChildItem -Recurse | Where-Object {$_.Length -gt 100MB} | Out-File "large_files.txt"
* 로컬 PC 환경에 직접 적용되며 보안 정책 설정으로 명령어 허용 범위를 제한할 수 있습니다.
Tier 03

PowerShell 자율 AI 제어 기능

단순 질의응답을 넘어 로컬 OS와 직접 상호작용하는 시스템입니다.

자율 커맨드 타이핑 & 실행

사람 대신 PowerShell 터미널을 열고 파이프라인과 Cmdlet 명령어를 스스로 작성 및 입력하여 실행합니다.

로컬 파일 & 시스템 제어

디렉토리 정리, 프로세스 종료, 네트워크 상태 점검, 백업 스크립트 작성 등 Windows 로컬 환경을 종합적으로 조작합니다.

실시간 에러 디버깅 Loop

명령 실행 도중 구문 오류나 권한 에러가 발생하면 StdErr 로그를 읽어 스스로 명령어를 수정한 뒤 재시도합니다.

Deep Thought (연쇄적 생각)

RYIC 4B는 단순 질문 답변을 넘어, **한국어 어순과 문맥에 특화된 연쇄적 사고(Chain-of-Thought)** 프로세스를 적용하여 복잡한 수리/논리 문제도 단계별로 완벽히 풀어냅니다.

// 한국어 논리 추론 예시
"조건: A는 B보다 크고, B는 C의 절반이다. C가 10일 때 A의 최소값은?"
생각 과정: C=10 → B=5 → A > 5 이므로 정수일 경우 A ≥ 6
* 4B 파라미터 경량화 모델 중 최고 수준의 한국어 벤치마크 점수 달성.

4B 초경량 구조

4GB VRAM 이상의 일반 PC 환경 및 로컬 디바이스에서도 지연 없이 원활한 구동이 가능합니다.

PowerShell 네이티브

복잡한 Python 환경 설정이나 Docker 설치 없이 PowerShell 커맨드 하나로 구동 및 CLI 상호작용이 가능합니다.

한국어 특화 추론

한국어 자연어 이해, 정교한 요약, 코딩 파이프라인 생성 및 복잡한 논리 문제를 신속하게 처리합니다.
